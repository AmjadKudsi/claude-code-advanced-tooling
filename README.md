# Docusaurus

## Project Overview
Documentation website generator built with React. Monorepo with core packages and example site.

## Architecture
- Core: `packages/docusaurus/`
- Plugins: `packages/docusaurus-plugin-*/`
- Themes: `packages/docusaurus-theme-*/`
- Example site: `website/`

## Tech Stack
TypeScript, React 18+, Webpack 5, MDX, Jest
